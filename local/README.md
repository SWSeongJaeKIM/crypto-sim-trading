# local/ — PC 상주 실행용 모의투자 시스템

**Claude나 그 어떤 외부 AI API도 호출하지 않습니다.** 이 폴더의 코드만으로
사용자 PC에서 완전히 독립적으로 돈다. 사용량이 드는 건 Upbit 공개 API
호출(무료)뿐이다.

## 구성

- `strategies.py` — 조건식 전략 4종 (상위 폴더와 동일, 복사본)
- `portfolio.py` — 가상 계좌 모델 (상위 폴더와 동일, 복사본)
- `learner.py` — 전략 파라미터 자동 재조정 (상위 폴더와 동일, 복사본)
- `data_fetcher.py` — Upbit 1분봉 수집 (실시간 + 학습용 N일 히스토리)
- `lstm_model.py` — **LSTM 분류 모델**: 최근 60분 흐름(수익률, 거래량 변화,
  RSI, MACD, 볼린저 %b)을 보고 "다음 1분봉이 오를지/내릴지" 추론.
  조건식 전략과 동일한 `signal(df)` 인터페이스(`LSTMStrategy`)로 노출되어
  같은 리더보드에서 경쟁한다.
- `storage.py` — 로컬 SQLite(`trading.db`) 저장소 (포트폴리오/거래/스냅샷/파라미터/
  LSTM 학습기록/실전 예측 적중 기록)
- `main_loop.py` — **상주 실행 스크립트**. 매 1분 5개 전략(조건식4+LSTM1)이
  신호 계산 → 모의 매수/매도 → SQLite 저장을 반복. 전략마다 "리셋" +
  "누적" 포트폴리오 2개를 동시에 운영한다(아래 "리셋 vs 누적" 참고).
  LSTM이 낸 예측은 다음 사이클에 실제가로 확정해서 적중여부를 기록.
  매일 새벽 4시(로컬시간)에 LSTM을 최근 30일 데이터로 **추가학습(파인튜닝)**.
  지금 뭘 하고 있는지(대기중/데이터수집중/학습중 등)를 매 단계마다 SQLite에
  기록해서 대시보드에서 볼 수 있게 한다.
- `dashboard.py` — 로컬 Flask 웹서버. "7일 리셋" / "누적" 두 그룹으로 나눈
  전략별 **수익률(%)과 손익금액(원)** 리더보드, 지금 진행 상황 표시줄,
  최근 거래, **LSTM 학습 기록(코인별 정확도 추이)**, **LSTM 실전 예측
  적중률(코인별)**을 보여준다.
- `retrain_now.py` — 새벽 4시까지 기다리지 않고 지금 바로 LSTM 재학습을
  1회 실행하고 싶을 때 쓰는 보조 스크립트.
- `migrate_dual_portfolio.py` — 리셋/누적 이중 포트폴리오 구조 도입 전에
  이미 쌓여있던 옛 데이터를 "누적" 포트폴리오로 1회 이전하는 스크립트.

## 리셋 vs 누적 포트폴리오

전략(조건식 4개 + LSTM 1개) 각각을 "리셋"과 "누적" 두 개의 독립된 가상
계좌로 동시에 돌린다. 매매 판단(사고 팔지 여부)은 둘이 완전히 같고,
계좌 상태(현금/보유량/손익)만 따로 쌓인다.

- **리셋 포트폴리오** (`<전략>__reset`): 포트폴리오가 만들어진 지 7일이
  지나면 다음 사이클에서 자동으로 1000만원으로 초기화된다. "이 전략이
  최근 1주일 동안 잘하고 있나"를 보기 위한 용도 — 예전의 우연한 거래
  하나가 전체 성과를 계속 왜곡하지 않는다.
- **누적 포트폴리오** (`<전략>__cumulative`): 한 번도 리셋하지 않고
  시스템을 처음 돌린 시점부터 지금까지 그대로 쭉 이어간다. "이 전략이
  장기적으로 얼마나 벌었나"를 보기 위한 용도.

리셋 주기는 `main_loop.py`의 `RESET_DAYS` 상수(기본 7)로 바꿀 수 있다.

**기존에 이미 운영하던 환경이라면**: 이 구조가 추가되기 전 데이터가
`ma_cross_rsi` 같은 옛 이름으로 남아있을 텐데, `git pull` 후
`python3 migrate_dual_portfolio.py`를 **한 번만** 실행하면 그 데이터가
자동으로 `<전략>__cumulative`로 이전된다(리셋 포트폴리오는 이 시점에
1000만원으로 새로 시작). 실행 안 해도 시스템은 돌지만, 기존 손익 이력이
새 "누적" 그룹에 안 보이고 처음부터 다시 쌓이게 된다.

## LSTM 학습 방식 (추가학습)

매일 재학습할 때마다 모델을 처음부터 새로 만들지 않고, **기존에 저장된
가중치를 불러와서 이어서 학습(파인튜닝)**한다. 그래서:

- 예전에 학습한 패턴을 급격히 잃지 않으면서 최근 데이터를 반영
- 학습할 때마다 `model_trainings` 테이블에 기록이 **누적**된다 (덮어쓰지 않음)
  — 언제, 어떤 코인, 최초학습/추가학습 여부, 데이터 기간, 샘플 수, 검증
  정확도를 전부 남겨서 대시보드에서 정확도가 올라가는지/내려가는지 추이를 볼 수 있다.
- 모델 가중치 파일도 두 군데 저장: `models/{coin}_lstm.pt`(최신, 실제
  추론에 쓰는 파일, 매번 덮어씀)와 `models/history/{coin}_lstm_YYYY-MM-DD.pt`
  (그날짜 사본, 나중에 특정 날짜 모델로 되돌리거나 비교하고 싶을 때 사용).

## 이 모델이 "좋은 모델"인지 어떻게 아나

대시보드에서 세 가지를 같이 봐야 한다 — 서로 다른 걸 알려준다:

1. **상단 리더보드의 수익률(%)/손익금액(원)** — 실제로 그 전략(조건식 또는
   LSTM)이 돈을 벌고 있는지. 가장 직접적인 지표.
2. **"LSTM 학습 기록"의 검증 정확도(val_accuracy)** — *과거* 학습 데이터
   중 일부를 떼어놓고 맞혀본 정확도. 모델이 과거 패턴을 얼마나 잘 외웠는지는
   보여주지만, 실시간 시장에서도 그만큼 맞을지는 보장 안 함.
3. **"LSTM 실전 예측 적중률"** — 실제로 매분 신호를 낸 뒤 1분 뒤 가격이
   그 방향으로 움직였는지 누적 집계한 것. *지금 이 순간* 모델이 실전에서
   얼마나 맞고 있는지 가장 직접적으로 보여준다. 50%보다 꾸준히 높으면
   방향을 어느 정도 맞히고 있다는 뜻 (암호화폐 1분봉은 노이즈가 매우
   커서 50% 근처가 나오는 게 보통이다).

정확도가 높아도 수익률이 나쁠 수 있고, 반대로 정확도가 낮아도(예: 큰 상승만
잘 잡으면) 수익률이 좋을 수 있다 — 그래서 수익률이 최종 판단 기준이다.

## 설치 (최초 1회)

```bash
# Python 3.10+ 필요. 가상환경 권장.
cd local
pip install -r requirements.txt
```

GPU 없어도 된다 (CPU로 충분 — LSTM이 아주 작은 모델이라 1분 추론은 수 ms,
하루 1회 재학습도 노트북 기준 몇 분 내).

## 실행

터미널 2개를 띄운다 (또는 백그라운드로):

```bash
# 터미널 1: 매매 엔진 (계속 실행)
python3 main_loop.py

# 터미널 2: 대시보드
python3 dashboard.py
```

- 첫 실행 시 LSTM 모델이 없으므로 `main_loop.py`가 최근 30일치 1분봉을
  받아서 자동으로 최초 학습을 수행한다 (코인당 수 분, 네트워크 속도에 따라
  다름 — 1분봉 30일치는 페이지네이션으로 많은 호출이 필요해 다소 오래 걸림).
- 이후로는 매분 사이클이 돈다. Ctrl+C로 안전하게 종료 가능 (현재 사이클
  끝나고 정지).
- 대시보드: `http://localhost:5000`. 같은 와이파이의 폰에서 보려면
  PC의 사설 IP:5000 (Windows `ipconfig`, Mac `ipconfig getifaddr en0`로 확인).

## 24시간 계속 돌리기

회사에 가 있어도 집 PC가 계속 돌아야 하므로:

- **Windows**: 작업 스케줄러로 로그온 시 `main_loop.py`, `dashboard.py`를
  자동 시작하도록 등록 (또는 그냥 터미널 창을 열어두고 PC를 절전모드 안
  들어가게 설정).
- **Mac/Linux**: `nohup python3 main_loop.py &` 로 백그라운드 실행하거나,
  `launchd`(Mac)/`systemd`(Linux) 서비스로 등록.
- PC가 절전모드로 들어가면 스크립트도 멈추니, 전원 설정에서 "절전 모드
  안 함"으로 바꿔두는 게 중요하다.

## 데이터는 어디 저장되나요

전부 로컬 파일:
- `trading.db` — SQLite (포트폴리오, 거래기록, 스냅샷, LSTM 학습기록)
- `models/*.pt` — 코인별 최신 LSTM 가중치 (추론에 쓰는 파일)
- `models/history/*_YYYY-MM-DD.pt` — 날짜별 모델 가중치 백업
- `data_cache/*.csv` — 학습용으로 받은 1분봉 캐시
- `run.log` — 실행 로그

전부 `.gitignore`에 포함되어 있어 git에는 올라가지 않는다 (PC마다 자기
데이터로 새로 쌓임).
